# 무한매수법 백테스터

무한매수법 **V4.0**과 **V2.2**를 과거 가격 데이터로 검증하는 정적 웹페이지입니다 (GitHub Pages).

- **V4.0**: 실제 운영 중인 자동매매 코드의 주문 계산 로직(`generate_v4_orders_local`)을 그대로 옮겼습니다.
  같은 가격 데이터로 실운영 코드와 하루씩 대조했고, SOXL 20분할(2018~)과 TQQQ 40분할(2015~)에서
  T값·평단·보유수량·누적손익·다음 날 주문표가 모두 일치합니다.
- **V2.2**: 라오어 원문 규칙입니다 (T = 매입원가 ÷ 1회매수금, 소진 시 쿼터손절).
- 두 전략을 같은 구간에서 겹쳐 비교할 수 있고, 마지막 날 기준 다음 거래일 주문표도 보여줍니다.

## 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 화면 (설정, 차트, 표) |
| `engine.js` | 백테스트 엔진 (V4.0, V2.2) — 브라우저/Node 공용 |
| `data/*.json` | 일봉 OHLC (야후 파이낸스, 액면분할 반영·배당 미반영) |
| `scripts/update_data.py` | 데이터 갱신 스크립트 |
| `tickers.txt` | 자동 갱신할 종목 목록 |
| `.github/workflows/update-data.yml` | 평일 미국장 마감 후 데이터 자동 갱신 |

## 체결 가정

- LOC 매수: 종가 ≤ 주문가 → 종가 체결 / LOC 매도: 종가 ≥ 주문가 → 종가 체결
- 지정가 매도: 장중 고가 ≥ 주문가 → 주문가 체결 / MOC: 종가 체결
- 주문은 그날 종가 확정 후 계산해서 다음 거래일에 체결 판정

## 종목 추가

`tickers.txt`에 티커를 한 줄 추가하고 커밋하면 다음 자동 갱신 때 받아옵니다.
바로 받으려면 Actions 탭에서 "가격 데이터 갱신"을 수동 실행하세요.

## 로컬 실행

```
python scripts/update_data.py      # 데이터 받기 (yfinance 필요)
python -m http.server 8000         # http://localhost:8000
```

주소 끝에 `#run`, `#run-v22`, `#run-both`를 붙이면 기본 설정으로 바로 실행합니다.

과거 성과는 미래 수익을 보장하지 않습니다. 세금·환율·배당은 반영하지 않았습니다.
